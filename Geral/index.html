O que aconteceu?

Ao aplicar display: flex; no container, ele se transformou em um "flex container" e os elementos filhos ("flex items") foram dispostos em linha (eixo horizontal principal), lado a lado, em vez de empilhados como fariam no comportamento padrão em bloco.

Explicação dos valores:

  • row (padrão): Os itens se alinham em linha, da esquerda para a direita. O eixo principal é horizontal.
  • column: Os itens se empilham, de cima para baixo. O eixo principal passa a ser vertical.
  • row-reverse: Os itens se alinham em linha, mas a ordem é invertida (da direita para a esquerda). O eixo principal começa no lado direito.
  • column-reverse: Os itens se empilham, mas de baixo para cima. O eixo principal começa na parte inferior.

Explicação dos valores:

  • flex-start (padrão): Todos os itens são empurrados para o início do eixo principal (esquerda, por padrão).
  • flex-end: Os itens são empurrados para o final do eixo principal.
  • center: Os itens são centralizados ao longo do eixo principal.
  • space-between: O espaço extra é distribuído igualmente entre os itens. O primeiro fica colado no início e o último no final.
  • space-around: O espaço extra é distribuído ao redor dos itens. O espaço nas bordas externas é metade do espaço entre os itens internos.
  • space-evenly: O espaço extra é distribuído igualmente tanto entre os itens quanto nas bordas externas (espaçamentos idênticos).

Explicação dos valores:

  • stretch (padrão): Se os itens não tiverem altura definida, eles "esticam" para preencher toda a altura do container (eixo transversal).
  • flex-start: Os itens são alinhados ao topo do eixo transversal.
  • flex-end: Os itens são alinhados à base do eixo transversal.
  • center: Os itens são centralizados verticalmente (no eixo transversal).
  • baseline: Os itens alinham suas bases de texto. Pode ser diferente de center ou bottom se a fonte ou altura de linha variarem.

O flex-wrap: wrap; permite que os itens "caiam" para a linha de baixo quando não cabem mais na largura do container. Sem ele, os itens espremeriam para caber em uma única linha.

Ao combinar com align-content, podemos controlar como as múltiplas linhas se distribuem no eixo transversal do container (funciona de forma similar ao justify-content, mas para blocos de linhas).

Nível 4 — Propriedades dos Itens Flex

Exercício 7 — Crescimento proporcional (flex-grow)

Objetivo: Fazer os itens dividirem o espaço extra proporcionalmente.

Grow: 1
Grow: 2
Grow: 1

O container tem espaço livre. Os itens com flex-grow: 1 pegam 1 parte desse espaço livre, enquanto o item com flex-grow: 2 pega o dobro dessa quantidade (2 partes).

Exercício 8 — Encolhimento e base (flex-basis e flex-shrink)

Objetivo: Controlar como cada item encolhe quando falta espaço (simule redimensionando a janela).

Shrink: 2
Basis: 200px
Shrink: 1
Basis: 200px
Shrink: 0
Basis: 200px

A soma da base (3x200px = 600px) excede o tamanho do container (500px). Logo, há necessidade de encolher.

O Item 3 (shrink 0) não encolhe e mantém seus 200px. O Item 1 (shrink 2) perde o dobro do tamanho em relação ao Item 2 (shrink 1) para fazer tudo caber.

Exercício 9 — Reordenação e alinhamento individual (order e align-self)

Objetivo: Perceber que flex items têm posicionamento independente e podem ter sua ordem visual alterada.

Original 1 (Order: 4, Top)
Original 2 (Center)
Original 3 (Order: 1, End)
Original 4

Usando a propriedade order, o terceiro elemento HTML passa a aparecer na frente (order: 1) e o primeiro elemento vai para o final da fila (order: 4).

Além disso, usamos align-self para sobrescrever o align-items do pai. O item Original 1 ficou no topo (flex-start), o Original 2 no meio (center) e o Original 3 na base (flex-end).
