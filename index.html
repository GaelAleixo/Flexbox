Guia de Bolso do Flexbox CSS

Diferencie perfeitamente as diretivas destinadas ao elemento pai (Container) das diretivas dos elementos filhos (Itens).

PAI

Propriedades do Container Pai (Flex Container)

display: flex | inline-flex

Define o container como flexível. Obrigatoriamente a primeira propriedade a ser declarada para habilitar o uso do Flexbox.

  • flex: O container se comporta como um elemento de bloco.
  • inline-flex: O container se comporta como um elemento inline (lado a lado com outros inline).

flex-direction

Orienta o sentido dos itens, estabelecendo o eixo de distribuição primário (eixo principal).

  • row: Esquerda para a direita (horizontal padrão).
  • row-reverse: Direita para a esquerda.
  • column: Cima para baixo (vertical).
  • column-reverse: Baixo para cima.

justify-content

Alinha os itens no eixo principal. Extremamente útil para lidar com a distribuição de espaços vazios sobressalentes.

  • flex-start / flex-end: Encostados no início / no fim.
  • center: Agrupados perfeitamente ao centro.
  • space-between: Primeiro colado à esquerda, último colado à direita.
  • space-around: Margens laterais idênticas para cada box.
  • space-evenly: Espaço em branco rigorosamente uniforme em todos os cantos.

align-items

Define o comportamento padrão de alinhamento vertical/transversal de todos os itens de uma mesma linha.

  • stretch: Estica os filhos de forma uniforme até a altura máxima do pai.
  • flex-start / flex-end: Alinha no topo / na base.
  • center: Alinha de forma centralizada verticalmente.
  • baseline: Alinha os caracteres de texto na mesma linha invisível.

flex-wrap

Permite a quebra de linha quando o container fica pequeno demais para alojar todos os itens em uma única fileira.

  • nowrap: Espreme os itens impedindo a quebra de linha (padrão).
  • wrap: Permite que elementos que estourarem caiam para a fileira de baixo.
  • wrap-reverse: Inverte a posição das linhas geradas.

gap

Cria o espaçamento de forma automatizada entre os boxes internos do container de forma limpa.

  • Elimina: O uso problemático e antigo de margin manual que gerava margens indesejadas nas extremidades externas do pai.
FILHO

Propriedades Individuais (Flex Items)

flex-grow

Capacidade de um item de se expandir de forma proporcional para preencher o espaço livre do container.

  • 0: Mantém tamanho padrão ou estipulado (padrão).
  • 1: Preenche o espaço restante de maneira amigável.
  • 2: Se outros possuírem valor 1, este item crescerá na proporção do dobro de sobra de tela.

flex-shrink

Capacidade de um item de diminuir proporcionalmente de tamanho caso os tamanhos combinados de todos estourem o pai.

  • 1: Diminui de acordo com a proporção geral de todos os outros (padrão).
  • 0: Recusa terminantemente o encolhimento, forçando overflow ou estiramento de layout para o lado externo se for o caso.

flex-basis

Define o tamanho base padrão inicial de um elemento antes que os fatores de encolhimento ou crescimento entrem em ação.

  • auto: Utiliza as dimensões de largura (width) ou altura (height) definidas por CSS comum.
  • [valor px / %]: Define um tamanho estático, ex: 200px ou 30%.

align-self

Permite a um item específico ignorar o alinhamento transversal (align-items) global determinado pelo pai.

  • auto: Respeita o pai (padrão).
  • flex-start / flex-end: Sobe sozinho ou desce sozinho na vertical/eixo transversal.
